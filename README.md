## 🚀 Key Features

- **Interactive Command-Line Terminal**: Simulated PowerShell / Linux shell allowing visitors to query `whoami`, `sysinfo`, `skills`, `certifications`, `uptime`, and `contact` directly.
- **Enterprise Capabilities & Domains**: Deep dive into Active Directory, Cisco Switching, VMware ESXi & Hyper-V, Veeam Backup v12, and Cloud Infrastructure.
- **Interactive Skills Matrix**: Filterable grid across Systems, Virtualization, Networking, Cloud, ERP, and Hardware.
- **Career Journey Timeline**: Detailed breakdown of 4 enterprise roles with accomplishments and technology stacks.
- **Verified Credentials & Lightbox Viewer**: High-resolution certificate modal viewer for the 320-hour Academic Cloud Engineering Program (IT Gate Academy) plus MCSA, CCNA, VMware, and Sophos certifications.
- **Architecture Blueprints**: Real-world enterprise network diagrams and disaster recovery targets (RPO/RTO).
- **Direct Contact & Download**: One-click CV PDF download, email copy with feedback, direct WhatsApp and phone links.
- **Theme Support**: Seamless Dark Mode and Light Mode with persistence.
- **Zero Build Dependencies**: Pure HTML5, modern Tailwind CSS, and Vanilla JavaScript for instant GitHub Pages deployment.
